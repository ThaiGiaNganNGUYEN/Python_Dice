# Synopsis
Python Dice Roller

## Description
A random dice roller using Python that rolls a number of dice chosen by user

## Contents
README - The manual file
dice.py - Implementation of Python Dice Roller

## Compilation
python3 dice.py

## Execution Instruction
When prompted "Enter the amount of dice (1-10): ", enter the number of dice you want to roll (i.e. 3)
